## Implemented in this tagged release

### Core runtime
- FastAPI application with health, readiness, metrics, diagnostics, chat, analysis, portfolio, paper-trading, backtest, memory, tool, workflow, connector, governance, and project endpoints
- Deterministic runtime wiring for orchestration, observability, memory, tooling, workflows, connectors, project intelligence, and delivery analysis
- Optional SQLite-backed persistence for memory, workflow metadata, and project workspaces

### Deterministic market intelligence
- OHLCV normalization and market-data abstractions
- Market-context, underlying-analysis, confluence, portfolio, paper-trading, and historical-replay engines
- Quant modules for EMA, RSI, MACD, swing points, market structure, trend, momentum, volume, support/resistance, and VWAP

### Frontend and voice
- React/Vite frontend for diagnostics, chat, analysis, portfolio, memory, tools, workflows, projects, connectors, governance, automation, and paper trading
- Voice panel with browser speech-recognition and speech-synthesis adapters

### Integrations and governance
- Optional Gemini adapter
- Read-only GitHub and Jira connectors with fixed-host validation and bounded capabilities
- Allowlisted tool plans, exact approvals, and restart-safe workflow orchestration
- Project intelligence snapshots and delivery briefs based on Jira/GitHub evidence

## Operational boundaries in v1.0.0
- LIVE trading is unsupported
- Paper execution requires explicit authorization
- Automation does not auto-run on startup
- External credentials stay server-side
- GitHub collaboration writes remain disabled by default
